# Projeto TI1

## Descrição

Este projeto foi desenvolvido durante a disciplina de Trabalho Interdisciplinar I (TI1).

O objetivo do projeto é a criação de um sensor de fumaça, umidade e temperatura com alarme para casos de incêndio.

## Linguagem utilizada

- C++

## Execução

Caso 1 - se o sensor não detectar nenhuma avaria  na temperatura, umidade ou sinal de fumaça, o led verde será aceso.

Caso 2 - Se forem detectados níveis um pouco acima da média, o led amarelo acende e o buzzer emite um som leve de alerta.

Caso 3 - Caso as leituras estejam muito acima do padrão, o led vermelho será aceso e o buzzer emitirá um som forte.
